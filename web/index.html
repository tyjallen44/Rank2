              ▸ HubSpot Workflow — Setup Guide
            
            

              

                Connect a HubSpot form to Pulse so each submission generates a Hospital Network report and emails the requester.
                The reliable path is an Operations Hub Custom Code action (it can send our exact fields and the secret header);
                the snippet below is pre-filled with your live webhook URL.
              


              
1 · Build the form

              Create (or reuse) a HubSpot form that captures — and maps to contact properties —
              Organization name, Headquarters (city, state), Website URL,
              Name, Email, and optionally Job title.

              
2 · Create a workflow

              Automation → Workflows → Create → Contact-based. Set the enrollment trigger to
              Form submission = your form.

              
3 · Store the secret

              In the workflow, add a secret named PULSE_WEBHOOK_SECRET and paste the
              Shared secret shown above. (Keeps the secret out of the code body.)

              
4 · Add a “Custom code” action

              Choose Node.js. Under Property to include in code, add the contact properties for organization name,
              headquarters, website, name, email, and job title — using the input names in the snippet
              (organization_name, headquarters, website_url, requester_name,
              email, jobtitle). Then paste:
              

                
              

              


              
5 · Test & turn on

              Submit the form with a real hospital email, then watch Recent Requests below for the row
              (Sent when affiliation is confirmed, Follow-up when it isn’t). Turn the workflow on.

              

                No Operations Hub? The native “Send a webhook” action can’t set a custom header or our field
                names — append the secret as a query parameter instead (…/network-request?key=YOUR_SECRET), and
                relay the payload from your own backend, or use the Custom Code action above.

Release Notes

      
What's new in Pulse.


      


        

          
Version 1.09

          
Released September 22, 2026

        


        

          
New Features


          

            
New Home Page

            
Signing in now lands on a Home page: the RLDatix mark, what Pulse does, a featured block for a welcome / walkthrough video, and one-click cards for every report type. On Home the left navigation shrinks to an icon rail — hover it to expand; it returns to full width on every other page. The featured block is admin-editable (Learn → Manage Content → Home page); paste a YouTube, Vimeo or Loom link on its own line and it embeds as a player.

          


          
Naming


          

            
Reports Are Now AI Reputation Reports

            
Pulse is now the AI Reputation Analysis Platform. Every report, cover, scorecard, email and page that said "AI Visibility" now says AI Reputation — including the AI Reputation Score and Pulse Score (AI Reputation) labels. Scoring, pillars and methodology are unchanged; only the name moved. Reports generated before this release keep their original wording.

          


          
Trends


          

            
Track Hospital Networks and Community Health Centers

            
Trends now follows a Hospital Network's system score over a fixed facility roster (monthly by default) and Community Health centers on the Community Health Edition rubric, alongside hospitals, service lines and practices. Start tracking from a finished report's completion screen, a History row, Find an organization on Home, or the Trends page.

          


          

            
Trend Report Redesigned

            
The Trend Report opens with a headline sentence, three big tiles (latest score, change since first snapshot, quartile), a zoomed score chart with named quartile bands, a pillar chart and a plain-English line per pillar. Each tracked entity has an editable Display name used as the report title.

          


          

            
Needs Attention, Reviewed & Notes

            
A Needs attention badge flags a score fall, an overdue analysis run, a rubric mismatch, a mixed-rubric history or an unconfirmed roster. Click it for the explanation and the fix; Reviewed hides a flag until new data raises it again. Dated notes record what changed and appear as markers on the chart and in the Trend Report.

          


          

            
Manage Roster & Add a Hospital the AI Missed

            
Every tracked entity with a fixed roster has a Manage roster pop-over: the full list of facilities or locations, Remove per entry, and a roomy add form that verifies the entry against its Google listing (and CMS Care Compare for hospitals) before it joins. Each change is recorded as a dated Roster changed note. The Hospital Network page and the Trends add flow also offer Add a hospital the AI missed, remembered for future discoveries of that system.

          


          

            
Create Full Report, Owner & Duplicate Warning

            
Create full report in Details launches the Deep Diagnostic or Hospital Network report immediately with the tracked settings; the result also joins the trend. The list shows the Owner who set up tracking, and adding an organization that is already tracked warns first and offers to open the existing entity. Search, filters and the Track New Entity button stay pinned while the list scrolls, and an open Details panel is framed with its row.

          


          
Deep Diagnostic Evidence


          

            
What AI Assistants Actually Said

            
Every Deep Diagnostic now puts eight fixed patient-style questions to real AI assistants (Claude always; ChatGPT and Gemini when configured) and records how often the organization was named, who was named instead and which pages were cited. An observational check that never changes the score, shown on the completion screen and in the PDF.

          


          

            
Verified Quality Signals & Score Evidence

            
The CMS Care Compare star rating and Leapfrog safety grade are now fetched directly from those sources during the analysis run and override the model where they disagree. Each report carries a Score Evidence chip (High / Medium / Low) with the reason — review volume, whether CMS/Leapfrog were verified, whether live web search was available — on the completion screen, in History, in Trends and under the score in the PDF, which also lists the pages consulted. A Hospital-type run now always stays on the hospital rubric and says so when the analysis reads the organization as a clinic network.

          


          

            
Practice Profiles: Checked, Imported & Owner-Attested

            
For practices and service lines, every confirmed location's Google Business Profile is read directly (website link, phone, hours, photos, status, reviews) and tabled in the PDF; the reputation finding is built from that table instead of inferred. Add locations from your own list imports the practice's own location list (paste or CSV, matched to Google listings) for practices spread beyond the discovery radius. Known facts under Advanced options passes what the practice has told you — profiles claimed, review program start, location count — as owner-attested evidence.

          


          
Improvements


          

            
Simpler Report Forms

            
Find an organization on Home and organization suggestions in every form (from your team's History and Trends) prefill the type, market and specialty. Rarely-changed settings moved under Advanced options; a Start a report chooser opens the right report in two questions; the 14-day duplicate-run check offers the existing report before starting a new analysis run.

          


          

            
History for Everyone

            
Every signed-in user now sees every report (Partner accounts stay isolated). Run by is recorded for analysis runs started from Trends too. Search, filters and column headers stay pinned while the list scrolls, and downloads save the file directly instead of navigating the tab.

          


          

            
Scoring, Help & Learn

            
The reviews pillars now differentiate above 4.5★ so the strongest organizations can reach the top of the scale. Help pop-overs and the Learn / Methodology pages were rewritten for every change above, with new topics for Score Evidence, sources, the profile audit, roster management and Trends flags. Admins see estimated API spend per analysis run under Operations.

          


          
Fixes


          

            
Live Web Search Restored

            
Report narratives had silently been written without live web search after one allowed domain became unreachable; search is back, the report now says loudly when it is unavailable, and Score Evidence reflects it.

          


          

            
Report & Data Fixes

            
Hospital and Community Health main PDFs no longer render as teasers; practice and Community Health reports regained their live evidence; organization names with "&" render correctly; the Add to Trends button no longer sticks disabled after a slow location discovery; Trends entities created before sign-in are attributed to their owner in History.

          

        


        

          
Version 1.08

          
Released September 11, 2026

        


        

          
New Features


          

            
Hospital Network — Standard, Teaser & Full Detail, Automatically

            
Every Hospital Network run now produces all three reports at once: the standard report, a prospect Teaser (everything below the System AI Visibility score is blurred, with the call-to-action left readable), and a Full Detail report that combines the network report with the complete content analysis and a drafted, publication-ready remediation prescription for every finding. The old two-step "Detailed Content Analysis" is gone — the only remaining choice is whether to add the service-line listing scorecard.

          


          

            
Practice Reports Now Include Content & a Prescription

            
A Deep Diagnostic for a specialty practice now delivers one combined report: the four-pillar Pulse Score, a Diagnostic Assessment that cites the practice's verified content findings, and a full content-improvement prescription — publication-ready fixes that replace the former generic roadmap. An optional teaser blurs the prescription for prospect outreach.

          


          

            
Safety & Quality in Content Reports

            
Content reports now flag hospitals that are missing a Leapfrog Hospital Safety Grade or carry a low CMS star rating, and prescribe how to fix it. When a Leapfrog grade is missing, the prescription explains how AI models "fill the vacuum" with other safety signals (CMS stars, HCAHPS, infection data, news, reviews) — and the CMS-quality fix pitches the RLDatix Patient Experience & Growth survey suite.

          


          

            
Contents Index on the Content Report

            
The detailed Content Report now opens with a contents page that lists every finding from your summary and the exact page where its fix is addressed.

          


        


        

          
Improvements


          

            
A Faster, Simpler Report Setup

            
The Deep Diagnostic create flow is streamlined from roughly six steps down to two: the best-matching organization is auto-selected, the practice profile is folded into the options panel, and the location and practice-composite confirmations now happen inline — no more separate screens or a surprise confirmation after you click Run.

          


          

            
Right Website, Every Time

            
Content analysis now uses the organization's authoritative Google Business Profile website, with a manual Website URL override field — fixing cases where a guessed, wrong site was analyzed.

          


          

            
History, Cleaned Up

            
The History list now shows the organization name (not a filename), adds a Run By column, and sorts newest-first by time; the redundant Location column was removed. Content reports now appear in History, duplicate and blank rows were fixed, and each row's Downloads menu shows exactly the right set of files.

          


          

            
Navigation

            
Hospital Network is now the first item in the sidebar and the default landing page, with clearer icons for Hospital Network and Competitors Rankings.

          


        


        

          
Version 1.07

          
Released September 2, 2026

        


        

          
New Features


          

            
Student Health Clinics — Ranked AI Visibility

            
A new mode on Competitors Rankings compares on-campus university student health clinics against each other. Group them by state, by radius around a named school, or by athletic conference (Big 12, Big Ten, SEC, ACC, Pac-12, Big East, American, Mountain West). Pulse finds the clinics for you, lets you review and edit the list, then scores and ranks each one on a rubric built for campus clinics — Reviews & Reputation, Findability & Identity, Services & Access, and Machine-Readability — using each clinic's real Google rating. Download a branded ranked PDF and a spreadsheet, saved to your History.

          


          

            
National Entity Runs — Score a Whole List at Once

            
On the Hospital Network page, admins can switch to Bulk List and upload a spreadsheet of hospital systems. Pulse scores every system in the background — no individual reports to open — and hands back your file enriched with each system's Pulse Score, national quartile, and all four pillar scores, so sales can spot exactly where a system is weak. Runs are saved under National Entity Runs on the History page.

          


          

            
Request a Report From Your Website

            
A new website integration lets prospects request a Hospital Network report from a form on your site. Pulse verifies the request is from someone affiliated with the organization, generates the report automatically, and emails them a secure link — turning your website into a self-serve lead source. Admins configure it from a new Integrations tab, and a scoped Integrations Admin role can manage the integration without access to user administration.

          


          

            
Service Line Analysis

            
Pulse can now analyze a single hospital department or service line — for example Duke Orthopedics within Duke Health — as its own entity on the practice rubric, rolling up all of that service line's clinics. When a listing looks like a service line, Pulse detects it and asks you to confirm before treating it that way. Available across Deep Diagnostic, Competitors Rankings, Compare Two, and Event Preparation.

          


        


        

          
Improvements


          

            
Resume Long-Running Reports

            
Large bulk and Event Preparation runs are now far more resilient. They survive interruptions, show live progress on the History page while they work, and can be resumed right where they left off — already-completed entities are kept, so nothing is re-run or lost.

          


          

            
Deep Diagnostic — Clearer Scope

            
The Deep Diagnostic description now spells out exactly what it covers: a hospital, a hospital network, a specialty practice within a hospital, or a medical practice.

          


          

            
Streamlined Report Appendix & Methodology Page

            
The lengthy methodology appendix in reports has been replaced with a compact summary that links to a new public Methodology page — shorter reports, with the full detail always available and admin-editable.

          


          

            
Compact Report-Type Selector

            
The large report-type selection cards on the creation screens are now smaller and fit three across, so they no longer dominate the page.

          


          

            
SocialClimb Sign-In

            
Team members with an @socialclimb.com email can now sign in with an email-and-password account, the same way @rldatix.com users do.

          


          

            
Browser Tab Icon

            
Pulse now shows its own icon in the browser tab, making it easy to spot among open tabs.

          


        


        

          
Version 1.06

          
Released August 20, 2026

        


        

          
New Features


          

            
Learn Center

            
A new Learn section explains what Pulse is, what each report shows, who the reports are for, and how to get started. It is available inside the app and on a public page anyone can visit at careclimb.com/learn — handy for sharing with prospects before they have access. Admins can add, edit, reorder, and publish content directly on the page using simple Markdown, with a live preview and a built-in formatting reference.

          


          

            
Report Creation — Clearer Names

            
The report types have been renamed for clarity: Deep Diagnostic (formerly Pulse Diagnostic), Hospital Network (formerly Network Pulse), Competitors Rankings (formerly Patient Pulse), and Compare Two (formerly Pulse Comparison), with Event Preparation moved to the bottom of the list. The new names carry through to report titles, PDF covers, and downloaded file names.

          


        


        

          
Improvements


          

            
Hospital Network — Same Score as the Market View

            
The Hospital Network report now scores a health system on the same four pillars — Outcomes & Safety, Credentials & Recognition, Experience & Reviews, and Access & Fit — used in the Competitors Rankings and market reports. A system now reads an identical Pulse Score in both reports (shared for 30 days, whichever report runs first), so the numbers no longer diverge between the two views. The facility scorecard has been streamlined into a clean facility roster, and the report now leads with a clear system-level score.

          


          

            
Consistent 30-Day Caching Across All Reports

            
Every report type now reuses its results for 30 days — previously some reports were held for 90 days and the Hospital Network report only for the current day. This makes report behavior consistent and cuts unnecessary re-runs. Admins can always force a fresh analysis with Refresh data.

          


          

            
Data Date on Every Report

            
Each report footer now shows the date its underlying data was collected (Data MM/DD/YYYY). Because scores are reused for a period, this makes clear that a report reflects data as of a specific date rather than being recomputed on every view.

          


          

            
Cleaner Report File Names

            
Downloaded report file names are now Title-Cased — for example Endeavor-Health-Hospital-Network — for a more polished, professional look.

New Features


          

            
Patient Pulse — Three Report Formats

            
Patient Pulse now offers three report formats, chosen at the start of each run. Hospital Network — Bulk List Scoring

      
    

    

      Score an entire list of hospital systems at once, instead of one report at a time.
      Upload a spreadsheet of health systems and get the same file back with an AI Reputation
      Pulse Score, a national quartile, and all four pillar scores
      filled in for every entity — no individual reports to open, and nothing cluttering your report History.
    


    
What it's for

    

      The full Hospital Network report is built to brief one system in depth. Bulk List Scoring answers a
      different question: across a whole market, region, or target list — who's strong, who's weak, and where?
      It turns a list of prospects into a ranked, filterable dataset your team can act on in minutes.
    


    
How it works

    
1. On this page, keep the toggle on Bulk List (CSV).

    
2. Upload a CSV of systems. The only required column is a system name (any header containing “name”); optional city and state sharpen the match. Use the template for the exact format.

    
3. Pulse scores each system headlessly — no PDFs, no History clutter. Progress shows live.

    
4. Download the enriched CSV: your original file, untouched, with the results appended as new columns.


    
What you get

    

      
ColumnMeaning

      
        
Pulse_ScoreOverall AI Reputation score, 0–100

        
QuartileNational quartile (1st = top, 4th = bottom)

        
Outcomes & SafetyClinical quality and safety signals AI can cite

        
Credentials & RecognitionAccreditations, awards, national rankings

        
Experience & ReviewsPatient sentiment and review ratings

        
Access & FitFindability and match to what patients ask for

      
    

    

      Every pillar is on the same 0–100 scale as the report's bars. Any system that can't be scored is marked
      “Failure to run” so nothing is silently dropped.
    


    
How to read the results

    
The four pillar columns are the point. Sort or filter any one to instantly surface where a system is exposed:

    
Low Experience & Reviews → reputation-management opportunity

    
Low Access & Fit → structured-data / machine-readability opportunity

    
Low Credentials & Recognition → the system isn't getting credit for quality it already has

    

      A weak pillar is a concrete, defensible reason to start a conversation — and a direct map to the
      PX&G offerings that address it.
    


    
Good to know

    
Consistent scoring. Bulk uses the same four-pillar engine as the Hospital Market report — a system gets the same Pulse Score either way.

    
Fast and repeatable. Recent scores are reused from cache, so re-running a list is nearly instant and won't redo work already done.

    
Resilient. Long lists survive interruptions — an analysis run can be resumed and picks up where it left off.

    
Everything's saved. Each analysis run is stored under National Entity Runs on the History page, where you can re-download the enriched CSV any time.

Analyze a Hospital Service Line

      
    

    
Deep Diagnostic can score one department of a hospital system — for example Houston Methodist Orthopedics — as a single entity. Every clinic of that service line is rolled up, scored on the practice rubric, and listed with its own Google reputation. The whole flow is: pick the type, fill three fields, glance at the locations, run.


    
Set up the search

    
1. At the top of the form, set Analysis Type to Hospital Service Line. Do this first — the fields below change to match.

    
2. Health System: the system name only, e.g. HOUSTON METHODIST. If your team has run it before, a suggestion appears as you type — pick it and the rest of the form fills in. If you type the department too ("Houston Methodist Orthopedics"), it is trimmed automatically.

    
3. Service Line: the department, e.g. ORTHOPEDICS, CARDIOLOGY, ONCOLOGY.

    
4. Market: the city and state of the metro to analyze, e.g. HOUSTON / TX. Clinics within about 50 miles are included, so for a multi-state system choose the metro you care about. Then click Search.


    
Confirm and run

    
5. The best Google match becomes the flagship listing, shown on one line. Click change only if it picked the wrong clinic.

    
6. The Locations list fills in over 10–20 seconds (Run stays disabled until it does). It combines the other Google listings for the same brand — each with its address and star rating — with AI discovery of remaining clinics. Uncheck anything that isn't part of this service line. Everything checked is rolled into the score and appears in the per-location reputation table.

    
7. The Report Title is set for you (e.g. Houston Methodist Orthopedics) — click rename beside it to change what prints on the report. The practice profile is auto-classified from the service line — click change to override.

    
8. Click Run Diagnostic. Every analysis run produces the report and a teaser, plus the per-location reputation table. Physician sub-rows or a website override are under Advanced options if you need them.


    
How the reviews pillar is scored

    
Reviews & Reputation is computed from the checked locations — a review-count-weighted average of their Google ratings and their combined review volume — so it always agrees with the reputation table in the report. It is never taken from the parent hospital's main listing.


    
Started as a Specialty Practice by mistake?

    
If a Specialty Practice search resolves to a department of a larger system, an amber line under the title offers a one-click switch to Hospital Service Line that prefills both fields and re-runs the search.

    

  







  

    

      
Analyze Specialty Practices Within Hospitals (Batch)

      
    

    
Event Preparation can score a whole list of hospital service lines at once — e.g. the orthopedics departments across many systems. Because it's a batch, there's no per-row confirmation: Pulse detects and rolls up each service line automatically.


    
Prepare your CSV

    
Required columns: name, city, state — one row per entity. Add an optional specialty column and fill it to target a department; leave it blank to analyze the whole entity. Filling it makes service-line detection far more reliable.

    
name,city,state,url,specialty
Houston Methodist Orthopedics,Houston,TX,,Orthopedics
Duke Health Orthopedics,Durham,NC,,Orthopedics
Hospital for Special Surgery,New York,NY,,Orthopedics


    
Run it

    
1. Open Event Preparation. The event name is optional — it defaults to the file name.

    
2. Choose your CSV (grab Download Template for the exact format), then Upload & Resolve Entities.

    
3. On the Confirm step the entity type is detected from the file: rows with a specialty are treated as Specialty Practice, which turns on per-row service-line detection for the whole upload. Change it there if the detection is wrong.

    
4. Review the resolved matches on the Confirm Entities step, then run.

    
5. Each department is scored headlessly on the practice rubric — auto-detecting and rolling up the service line (anchored by your specialty value when provided).

    
6. Download the enriched CSV and the ZIP of all report PDFs. The analysis run is saved under Event Runs on the History page, where it can also be resumed if interrupted.


    
Tips

    
• Name each row as "[System] [Specialty]" (e.g. Houston Methodist Orthopedics) for the most reliable detection.

    
• The Specialty Practice setting applies to the whole upload — keep a service-line batch separate from a whole-hospitals batch.

    
• A row that can't be resolved to a parent system is scored as a standalone practice instead — filling the specialty column reduces that.
